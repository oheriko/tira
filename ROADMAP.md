## Roadmap

Tira is evolving to become the most intelligent package manager for script-based installations. Here's what's coming:

### ✓ Phase 1: Foundation (Current)
- **Basic installation tracking** - Download, execute, and catalog scripts
- **Simple rollbacks** - Remove packages from database
- **Script caching** - Hash-based deduplication and version pinning
- **Configuration system** - Flexible per-script and global settings
- **Cross-platform support** - Linux, macOS, Windows binaries

### ⚙ Phase 2: Smart Monitoring (Q1 2026)
- **Filesystem change detection** - Track what files each script modifies
- **Service discovery** - Detect systemd services, cron jobs, and daemons
- **Environment tracking** - Monitor PATH changes and environment variables
- **Dependency mapping** - Understand what scripts install via other package managers
- **Real rollbacks** - Actually undo filesystem and system changes

### ▓ Phase 3: AI-Powered Intelligence (Q2 2026)
- **Vulnerability scanning** - AI analysis of scripts before execution
- **Smart change prediction** - Predict what scripts will modify before running
- **Semantic rollbacks** - AI-guided rollback suggestions with context
- **Supply chain monitoring** - Detect when upstream scripts change unexpectedly
- **Community threat database** - Shared intelligence about malicious scripts

### ☁ Phase 4: Cloud & Collaboration (Q3 2026)
- **Cloud sync** - Backup and sync package databases across machines
- **Team management** - Org-wide policies and compliance reporting
- **Usage analytics** - Insights into your infrastructure's script dependencies
- **API access** - Integrate Tira intelligence into other tools
- **Enterprise features** - RBAC, audit logs, and policy enforcement

### ⚓ Phase 5: Ecosystem (Q4 2026+)
- **Plugin system** - Extend Tira with custom analyzers and integrations
- **IDE extensions** - Script analysis directly in your editor
- **CI/CD integration** - Validate scripts in your deployment pipeline
- **Package recommendations** - AI suggests better alternatives to scripts
- **Script marketplace** - Verified, secure scripts with community ratings

---

### Premium Features

While Tira's core will always be free, advanced AI features will power our premium offerings:

**Tira Pro** - AI vulnerability scanning, cloud sync, advanced analytics
**Tira Enterprise** - Team management, compliance reporting, custom policies
**Tira API** - Integrate our script intelligence into your own tools
